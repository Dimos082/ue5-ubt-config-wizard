# Changelog

## [0.1.1] - 2026-09-29

### Added

- Focused local desktop editor with a welcome screen, one-file settings view, add-setting dialog and separate optional build check.
- Staged XML changes, conflict-aware saving, backups and separate export.
- Synthetic application tests, cross-platform CI and owner-triggered draft releases.
- Readable light/night themes, screen-aware startup placement, always-editable build command,
  full catalog browsing, and attached-comment removal with setting deletion.
- Platform-specific profile-path tests that match Epic's documented Windows, macOS and Linux locations.

### Compatibility

- Python 3.12 and 3.13 are the declared application targets.
- No exact Unreal Engine installation is certified by this initial source delivery.
- Native build artifacts become available only after a successful owner-triggered release workflow.
